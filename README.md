# SEO Matrix & Handbook Web Project

A lightweight static website for enterprise SEO, AEO, and GEO strategy analysis. This project includes a homepage dashboard, a linked SEO handbook page, and supporting assets for styling and interactivity.

## Project Structure

- `index.html` — Main landing page with SEO tools matrix, workflow sections, and navigation.
- `seo-handbook.html` — Dedicated SEO handbook page with long-form guidance and handbook sections.
- `about.html` — About page placeholder for author or project details.
- `style.css` — Global styling for the website.
- `script.js` — JavaScript for navigation toggles, interactive filters, and clipboard functionality.

## Features

- Clean navigation between `Home`, `SEO Handbook`, and `About`
- Responsive menu toggle for mobile navigation
- Interactive table filters for tool categories
- Smooth scroll behavior and section highlights
- Copy-to-clipboard support for embedded code blocks

## Usage

1. Open `index.html` in a web browser.
2. Use the navigation links to switch between pages.
3. Click the CTA or handbook link to access `seo-handbook.html`.

## Notes

- This is a static project and works best served from a local filesystem or static web server.
- If navigation does not work as expected, verify the browser path and ensure all files are in the same project folder.
